## Project Details

**Project Title:**  
RepoSage

**Project Description:**  
RepoSage is an intelligent open-source mentorship platform that bridges the gap between finding an issue and writing the actual code. It handles everything between finding an issue and writing the actual code, making it easy for beginners to start contributing. It features smart issue matching, automated architecture diagrams via AI, context-aware AI chat, and a one-click "Start Contribution" button that automates the fork, branch, and draft PR setup in under 60 seconds.

**Tech Stack Used:**  
Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, shadcn/ui, OpenRouter + Groq (DeepSeek V3 / Qwen 2.5), NextAuth v5, Octokit, Upstash Redis
